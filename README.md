One original one-line joke about office life, written as a Python program
for make.fun's "One-Line Office Joke: 24-Hour Sprint" bounty, $2 in USDC.

## The joke

> My boss says we're a family here, so I asked HR if I can be adopted by another department.

## Run it

```sh
python3 main.py
```

The program writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), exactly as the bounty rules require:
UTF-8 text, 1–200 characters, a single line. Stdlib only, no network,
no randomness — every run writes the same bytes.
